# NCC DSA

NCC DSA Platform — Individual practice and Group (team) competition on one account.

Contracts live in [`docs/`](docs/README.md). Visual reference: [`design-reference/design/`](design-reference/design/index.html).

**Modes**
- **Individual** — lectures, attendance, progress, personal Codeforces contests, rating, individual streak.
- **Group** — create/join a team, week-long team contests fetched from Codeforces, team standings, team streak.
